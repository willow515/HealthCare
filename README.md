# 🏥 Health Track – SDG 3 Health & Wellness Monitoring Web Application

**Health Track** adalah aplikasi web pemantau kesehatan personal yang dirancang untuk mendukung **UN Sustainable Development Goal 3 (Good Health and Well-Being)**. Aplikasi ini memungkinkan pengguna untuk mencatat metrik kesehatan harian seperti durasi tidur, konsumsi air minum, dan kondisi *mood*, serta menyajikan analisis risiko kesehatan dan grafik tren harian.

---

## 🌟 Fitur Utama

- **Pencatatan Log Harian & Riwayat:** Memasukkan dan mengelola data harian (jam tidur, liter air, dan mood) serta menghapus log jika diperlukan.
- **Analisis & Imbauan Kesehatan Otomatis:** Memberikan penilaian risiko kesehatan dan saran rekomendasi secara otomatis berdasarkan rata-rata log pengguna.
- **Visualisasi Tren Tidur (*Sleep Trends*):** Menyajikan grafik interaktif untuk memantau fluktuasi pola dan kualitas tidur harian.

---

## 🛠️ Teknologi yang Digunakan

- **Back-End:** PHP
- **Front-End:** HTML5, CSS3, JavaScript
- **Data Visualization:** Chart.js / Custom JS Graph Library

---

## 🚀 Cara Menjalankan Proyek

1. **Prasyarat:**
   - Pastikan telah menginstal web server lokal seperti [XAMPP](https://www.apachefriends.org/) atau Laragon.

2. **Langkah-langkah:**
   - Clone repositori ini ke dalam folder `htdocs` (jika menggunakan XAMPP):
     ```bash
     git clone [https://github.com/username/HealthTrack-SDG3.git](https://github.com/username/HealthTrack-SDG3.git)
     ```
   - Buka Apache pada Control Panel XAMPP.
   - Buka browser dan jalankan `http://localhost/HealthTrack-SDG3`.
